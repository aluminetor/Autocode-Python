## 📖 Descripción

Repositorio personal dedicado al aprendizaje y la práctica de Python, desde los fundamentos del lenguaje hasta conceptos de nivel intermedio.

Su propósito es fortalecer la lógica de programación, desarrollar habilidades para resolver problemas y consolidar las bases necesarias para el desarrollo de software.

## 📂 Estructura del repositorio

| Directorio o archivo | Descripción |
|---|---|
| `Basic/` | Ejercicios y fundamentos de Python. |
| `Intermediate/` | Prácticas de programación de nivel intermedio. |
| `leetcodeEasy.py` | Resolución de problemas de LeetCode de nivel fácil. |
| `borrador.py` | Espacio de experimentación y pruebas de código. |

## 🎯 Objetivos de aprendizaje

- Dominar la sintaxis y los fundamentos de Python.
- Trabajar con estructuras de datos.
- Desarrollar habilidades de pensamiento lógico y algorítmico.
- Aplicar buenas prácticas de programación.
- Resolver desafíos de programación.
- Fortalecer las bases para el desarrollo backend.
